# Крестики — учёт вышивки

[English](README.md) · Русский

Календарь для подсчёта вышитых крестиков. Это не игра «крестики-нолики».
Введите число за день: приложение покажет итог месяца, итог года и среднее за весь год.
Незаполненные дни считаются нулевыми, поэтому среднее отражает регулярность занятий.

## Запуск

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Статические файлы можно разместить на GitHub Pages.
На iPhone или iPad откройте HTTPS-страницу в Safari и добавьте её на домашний экран.

## Возможности и границы

- Календарь, график по дням и необязательный режим двух панелей на широком экране.
- Экспорт и импорт JSON. Данные хранятся локально в браузере.
- Локальные шрифты и значки. Аккаунта, сервера и аналитики в приложении нет.
- Сейчас поддерживаются 2025 и 2026 годы. Для других лет нужно изменить исходник.

Перед очисткой данных сайта или сменой браузера экспортируйте записи.
Это небольшой счётчик прогресса, а не полный менеджер проектов рукоделия.
